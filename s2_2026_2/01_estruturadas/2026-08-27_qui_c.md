## 1. Consolidação Prática de Algoritmos
A turma desenvolveu programas em terminal para exercitar a integração entre laços de repetição e decisões lógicas:

1. **Cálculo de Média Aritmética (`aula06_media.c`):** Leitura de notas de alunos com ponto flutuante (`double`) e estrutura condicional para validação de aprovação.
2. **Crivo e Teste de Números Primos (`aula06_primos.c`):** Algoritmo que utiliza o laço `for` e o operador de resto (`%`) para testar divisores. Se encontrar divisor intermediário, interrompe o laço com `break`:

```c
#include <stdio.h>

int main() {
    int n, eh_primo = 1;
    printf("Digite um numero: ");
    scanf("%d", &n);

    if (n <= 1) eh_primo = 0;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            eh_primo = 0;
            break;
        }
    }

    if (eh_primo) printf("%d eh primo.\n", n);
    else printf("%d nao eh primo.\n", n);

    return 0;
}
```

3. **Padrões Numéricos no Console (`aula06_max_impar.c`):** Construção de pirâmides e matrizes de caracteres no terminal combinando laços `for` aninhados com índices de linha e coluna.

---

## Glossário
- **Break**: Comando de controle que força a interrupção imediata de um laço de repetição.
- **Teste de Primalidade**: Algoritmo para verificar se um número inteiro possui divisores positivos além de 1 e dele mesmo.
- **Laço Aninhado**: Utilização de um laço `for` dentro de outro para percorrer estruturas bidimensionais.
