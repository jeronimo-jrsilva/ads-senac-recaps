---

## 1. Laço `while` (Pré-teste): Controle por Sentinela e Acumulador
O laço `while` avalia a condição lógica antes de cada ciclo. Caso a condição seja falsa logo na primeira verificação, o corpo do laço não é executado.

### Exemplo 1: Acumulador de Notas com Parada por Sentinela Negativa
Neste padrão clássico, o programa lê sucessivas notas e acumula o somatório até que o usuário digite um valor sentinela negativo (ex: `-1`), encerrando a repetição.

```c
#include <stdio.h>

int main() {
    float nota = 0.0, soma = 0.0;
    int total = 0;

    printf("Digite uma nota (ou valor negativo para encerrar): ");
    scanf("%f", &nota);

    // O laço só executa enquanto a nota for válida (>= 0)
    while (nota >= 0.0) {
        soma += nota;
        total++;
        printf("Soma parcial: %.2f | Notas inseridas: %d\n", soma, total);
        
        printf("Digite a proxima nota (negativo para sair): ");
        scanf("%f", &nota);
    }

    if (total > 0) {
        printf("\nTotal de notas: %d\n", total);
        printf("Media final: %.2f\n", soma / total);
    } else {
        printf("\nNenhuma nota valida foi inserida.\n");
    }

    return 0;
}
```

## 2. Laço `do-while` (Pós-teste): Validação Obrigatória de Entrada
O laço `do-while` garante que o bloco de instruções seja executado **ao menos uma vez** antes de checar a condição lógica. É a estrutura recomendada para garantir que dados inseridos pelo usuário estejam dentro de uma faixa válida.

### Exemplo 2: Validação de Entrada no Intervalo [0, 10]
O programa repete a solicitação caso o usuário insira uma nota fora do intervalo permitido.

```c
#include <stdio.h>

int main() {
    float nota;

    // Executa ao menos uma vez e repete se o valor for inválido
    do {
        printf("Informe uma nota valida entre 0.0 e 10.0: ");
        scanf("%f", &nota);

        if (nota < 0.0 || nota > 10.0) {
            printf("[ERRO] Nota invalida! O valor deve estar entre 0 e 10.\n\n");
        }
    } while (nota < 0.0 || nota > 10.0);

    printf("\nNota aceita com sucesso: %.2f\n", nota);
    return 0;
}
```

## 3. Comparativo Prático: `while` vs. `do-while`

| Característica | Laço `while` (Pré-teste) | Laço `do-while` (Pós-teste) |
| :--- | :--- | :--- |
| **Momento da Avaliação** | Antes de entrar no laço. | Ao final de cada iteração. |
| **Execução Mínima** | 0 vezes (pode nunca executar). | 1 vez (sempre executa ao menos uma vez). |
| **Cenário Típico** | Leitura de arquivos, fluxos com sentinela. | Menus de navegação, validação de inputs do usuário. |

---

## Glossário
- **Laço `while`**: Estrutura de repetição condicional em C com teste lógico no início do bloco.
- **Laço `do-while`**: Estrutura de repetição com garantia de execução mínima de um ciclo e teste lógico no final.
- **Valor Sentinela**: Valor especial de entrada utilizado para indicar o término da leitura de dados.
- **Acumulador**: Variável que armazena a soma progressiva de valores ao longo das iterações de um laço.
