## 1. Diretrizes da 3ª Lista de Exercícios em C
O docente disponibilizou o caderno de exercícios com foco na integração de estruturas de repetição, vetores unidimensionais, matrizes e modularização por funções:

- **Escopo Prático:** Implementação de algoritmos clássicos de busca, ordenação elementar, cálculos de estatística básica em vetores e validação de matrizes quadradas.
- **Rigor de Modularização:** Exigência de divisão do código-fonte em arquivos de cabeçalho (`.h`), implementação de funções (`.c`) e módulo principal (`main.c`).
- **Data Limite de Entrega:** **09 de Setembro de 2026 (Quarta-feira)** via ambiente acadêmico institucional.

## 2. Boas Práticas de Implementação e Compilação
- **Passagem de Parâmetros por Referência (Ponteiros):** Uso de ponteiros para permitir que funções modifiquem o estado de variáveis externas e operem sobre blocos contíguos de memória.
- **Flags de Compilação Rígidas:** Recomendação de compilação via GCC com as diretivas `-Wall -Wextra -pedantic` para detecção precoce de conversões de tipo implícitas e vazamentos de memória.

---

## 💡 Orientação: Como Compilar Projetos C Modularizados (Múltiplos Arquivos)

Quando o projeto é dividido em arquivos de cabeçalho (`funcoes.h`), implementação das funções (`funcoes.c`) e o ponto de entrada (`main.c`), todos os arquivos `.c` devem ser passados conjuntamente ao compilador:

```bash
# 🐧 Linux (Terminal Bash / GCC)
gcc -Wall -Wextra main.c funcoes.c -o programa && ./programa

# 🪟 Windows (PowerShell / MinGW GCC)
gcc -Wall -Wextra main.c funcoes.c -o programa.exe; .\programa.exe

# 🍏 macOS (Terminal Zsh / Clang LLVM)
clang -Wall -Wextra main.c funcoes.c -o programa && ./programa
```

## Glossário
- **Lista de Exercícios**: Instrumento de avaliação formativa com problemas práticos para codificação e envio ao docente.
- **Modularização**: Prática de engenharia de software que divide um programa monolítico em componentes independentes e reutilizáveis (`.h` e `.c`).
- **Ponteiro**: Tipo de variável em C que armazena o endereço de memória física de outra variável.
- **GCC**: GNU Compiler Collection, compilador padrão para a linguagem C em ambientes Linux e sistemas POSIX.
