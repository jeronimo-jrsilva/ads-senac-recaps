## 1. Boas Práticas com `if` / `else if` / `else`
O professor reforçou a importância do encadeamento lógico correto:
- Evitar múltiplos blocos `if` isolados e redundantes quando os casos são mutuamente exclusivos, reduzindo o número de comparações e eliminando comportamentos inesperados.
- Tratar rigorosamente as condições de borda (por exemplo, intervalos entre faixas de classificação) para impedir lacunas lógicas onde nenhuma condição seja satisfeita.

---

## 2. Estudo de Caso: Cálculo e Classificação de IMC
Foi trabalhado em sala o exercício de cálculo do Índice de Massa Corporal ($\text{IMC} = \frac{\text{peso}}{\text{altura}^2}$), destacando:
- A correta manipulação de tipos de ponto flutuante (`float` / `double`).
- A aplicação sequencial das faixas de classificação da OMS sem sobreposição de limites:

```c
#include <stdio.h>

int main() {
    float peso, altura, imc;

    printf("Digite o peso (kg): ");
    scanf("%f", &peso);

    printf("Digite a altura (m): ");
    scanf("%f", &altura);

    if (altura <= 0) {
        printf("Altura invalida!\n");
        return 1;
    }

    imc = peso / (altura * altura);
    printf("IMC calculado: %.2f\n", imc);

    if (imc < 18.5) {
        printf("Classificacao: Abaixo do peso\n");
    } else if (imc < 25.0) {
        printf("Classificacao: Peso normal\n");
    } else if (imc < 30.0) {
        printf("Classificacao: Sobrepeso\n");
    } else {
        printf("Classificacao: Obesidade\n");
    }

    return 0;
}
```
