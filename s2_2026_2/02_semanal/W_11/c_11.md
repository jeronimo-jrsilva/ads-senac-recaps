## 1. As Quatro Fases do Pipeline de Compilação

O Professor Matheus demonstrou o ciclo interno executado por ferramentas como o GCC:

1. **Pré-processador (`cpp`):**
   - Trata todas as diretivas que se iniciam com `#` (`#include`, `#define`, `#ifdef`).
   - Insere o conteúdo textual dos arquivos de cabeçalho (`.h`) diretamente no ponto de chamada e substitui macros textualmente.
   - Gera o arquivo intermediário pré-processado (`.i`).
2. **Compilador (`cc1`):**
   - Converte o código C pré-processado em instruções de linguagem de montagem (**Assembly**) específicas para a arquitetura da máquina (x86_64, ARM).
   - Realiza análise léxica, sintática, semântica e otimização de registradores.
   - Gera o arquivo Assembly (`.s`).
3. **Montador / Assembler (`as`):**
   - Traduz as mnemônicas Assembly em código de máquina binário puro (zeros e uns).
   - Gera o **Arquivo Objeto** (`.o` / `.obj`), que ainda não é executável pois referências externas permanecem em aberto.
4. **Linker / Ligador (`ld`):**
   - Resolve os endereços das chamadas a funções externas da biblioteca padrão de C (como `printf`, `malloc` da `libc`) e de módulos compilados separadamente.
   - Une todos os arquivos `.o` em um único executável final (`.exe` ou ELF no Linux).

```bash
# Demonstração manual das fases via GCC
gcc -E main.c -o main.i    # 1. Pré-processamento
gcc -S main.i -o main.s    # 2. Compilação para Assembly
gcc -c main.s -o main.o    # 3. Montagem para Código Objeto
gcc main.o -o programa.exe # 4. Linkedição para Executável
```
