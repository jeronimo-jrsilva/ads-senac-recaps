A quinta aula de **Linguagem C** foi dedicada à introdução das **Estruturas de Repetição**, com foco absoluto no funcionamento, sintaxe e aplicações práticas do **laço `for`**.

---

## 1. A Anatomia do Laço `for`
O comando `for` é a estrutura de repetição ideal quando se conhece previamente o número de repetições ou quando se utiliza uma variável contadora.

Sua sintaxe organiza o fluxo em três partes obrigatórias na mesma linha:

```c
for (inicialização; condição de parada; incremento/decremento) {
    // Bloco de instruções executado a cada iteração
}
```

- **Inicialização:** Executada apenas uma vez, antes do primeiro ciclo (ex: `int i = 1`).
- **Condição:** Expressão lógica testada antes de cada ciclo. Se verdadeira, o bloco executa; se falsa, o laço encerra.
- **Incremento/Passo:** Atualização do contador realizada ao término de cada ciclo (ex: `i++` ou `i += razao`).

---

## 2. Prática em Sala: Contadores, Acumuladores e PA
O professor orientou a resolução de desafios individuais em programas separados para fixar a mecânica do laço:

1. **Contagem e Pares:** Iteração simples de 1 a 10 e impressão seletiva de números pares com o operador módulo (`i % 2 == 0`).
2. **Variável Acumuladora (Somatório):** Soma progressiva de todos os inteiros de 1 até um valor $N$ informado pelo usuário:

```c
#include <stdio.h>

int main() {
    int n, soma = 0;

    printf("Digite um numero: ");
    scanf("%d", &n);

    // O laço for acumula a soma de 1 até n
    for (int i = 1; i <= n; i++) {
        soma += i;
    }

    printf("Resultado da soma: %d\n", soma);
    return 0;
}
```

3. **Progressão Aritmética (PA):** Geração de sequências numéricas a partir de um valor inicial, uma razão de incremento e a quantidade de termos desejada.

---

## Glossário
- **Laço for**: Estrutura de repetição controlada por contador que executa um bloco de código enquanto a condição lógica for verdadeira.
- **Variável de Controle (Contador)**: Variável que armazena a contagem de iterações do laço, atualizada a cada ciclo.
- **Acumulador**: Variável que armazena a soma ou agregação progressiva de valores ao longo das iterações de um laço.
- **Iteração**: A execução individual de uma única repetição do bloco de comandos dentro de um laço.
