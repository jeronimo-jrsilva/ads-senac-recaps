## 1. Exercício Prático: Validação de CPF (1º Dígito Verificador)
O Professor Vinícius conduziu um exercício clássico de lógica e operações aritméticas em C: o cálculo e validação do primeiro dígito verificador de um CPF a partir de seus 9 primeiros dígitos:

- **Ponderação Regressiva:** Aplicação de pesos decrescentes (de 10 a 2) sobre cada um dos 9 primeiros dígitos.
- **Aritmética Modular (`% 11`):** Uso do operador resto de divisão para aplicar a regra da Receita Federal (se o resto for menor que 2, o dígito é 0; caso contrário, `11 - resto`).
- **Atendimento Individual em Laboratório:** Vinícius acompanhou a escrita do código nas bancadas, orientando na leitura correta de múltiplos inteiros via `scanf` e na estruturação das operações lógicas.

```c
#include <stdio.h>

int main(void) {
    int d1, d2, d3, d4, d5, d6, d7, d8, d9;
    int soma, resto, digito1;

    printf("=== VALIDAÇÃO DE CPF (CÁLCULO DO 1º DÍGITO VERIFICADOR) ===\n");
    printf("Digite os 9 primeiros dígitos do CPF separados por espaço: ");
    scanf("%d %d %d %d %d %d %d %d %d", 
          &d1, &d2, &d3, &d4, &d5, &d6, &d7, &d8, &d9);

    // Multiplicação dos 9 primeiros dígitos pelos pesos decrescentes de 10 a 2
    soma = (d1 * 10) + (d2 * 9) + (d3 * 8) + 
           (d4 * 7)  + (d5 * 6) + (d6 * 5) + 
           (d7 * 4)  + (d8 * 3) + (d9 * 2);

    resto = soma % 11;

    // Regra do primeiro dígito verificador do CPF
    if (resto < 2) {
        digito1 = 0;
    } else {
        digito1 = 11 - resto;
    }

    printf("\n--- RESULTADO ---\n");
    printf("Soma ponderada dos pesos: %d\n", soma);
    printf("Resto da divisão por 11: %d\n", resto);
    printf("Primeiro Dígito Verificador: %d\n", digito1);

    return 0;
}
```

## Glossario

- **Casting (Coerção de Tipo)**: Conversão explícita de um dado de um tipo para outro tipo na memória [Wikipedia](https://pt.wikipedia.org/wiki/Coer%C3%A7%C3%A3o_de_tipos).
- **Escopo de Variável**: Região do código fonte onde uma determinada variável é visível e acessível.
- **Precedência de Operadores**: Regras formais que determinam a ordem de avaliação de expressões matemáticas e lógicas [Wikipedia](https://pt.wikipedia.org/wiki/Ordem_de_opera%C3%A7%C3%B5es).
