A oitava aula de **Banco de Dados** com o Professor Alexandre foi uma imersão prática na sintaxe e semântica da linguagem SQL padrão ANSI, focando nos comandos de Linguagem de Definição de Dados (DDL) e Linguagem de Manipulação de Dados (DML).

---

## 1. DDL: Criação Estruturada com Restrições de Integridade

O Professor Alexandre conduziu exercícios detalhados sobre o comando `CREATE TABLE`, enfatizando a importância de definir tipos e restrições semânticas diretamente na criação:

- **Tipos de Dados:** Diferenciação prática entre tamanhos fixos (`CHAR`), variáveis (`VARCHAR`) e números decimais de precisão exata (`NUMERIC`/`DECIMAL`).
- **Restrições:** `NOT NULL`, `CHECK`, `PRIMARY KEY` e `FOREIGN KEY`.
- A aula reforçou o perigo de tabelas criadas sem restrições explícitas, demonstrando como a falta de integridade física abre brecha para inconsistência nos dados de produção.

---

## 2. DML: Inserção e Consultas Filtradas

Foram exercitadas as operações fundamentais de manipulação:

- **Comando `INSERT INTO`:** Inserção de tuplas com especificação explícita das colunas e prevenção de erros de descompasso de ordem.
- **Comando `SELECT` com Filtros `WHERE`:** Construção de expressões lógicas utilizando operadores relacionais (`=`, `<>`, `>`, `<`) e conectivos booleanos (`AND`, `OR`, `NOT`).
- **Precedência de Operadores:** O Professor Alexandre frisou a relevância de parênteses para delimitar a ordem de avaliação quando conectivos `AND` e `OR` coexistem na mesma cláusula `WHERE`.

```sql
-- Criação de tabela de clientes e consultas com filtros compostos
CREATE TABLE Cliente (
    id_cliente INT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    cidade VARCHAR(50) NOT NULL,
    limite_credito DECIMAL(10,2) DEFAULT 0.00 CHECK (limite_credito >= 0)
);

-- Inserção de registros com lista explícita de campos
INSERT INTO Cliente (id_cliente, nome, cidade, limite_credito)
VALUES 
    (1, 'Maria Santos', 'Fortaleza', 5000.00),
    (2, 'Carlos Lima', 'Caucaia', 2500.00),
    (3, 'Ana Ferreira', 'Fortaleza', 8200.00);

-- Seleção com filtro booleano composto
SELECT id_cliente, nome, limite_credito
FROM Cliente
WHERE cidade = 'Fortaleza' AND limite_credito > 3000.00;
```
