A décima segunda aula de **Linguagem C** com o **Professor Matheus** introduziu o conceito formal de **Tipos Abstratos de Dados (TAD)**, estabelecendo as boas práticas de encapsulamento, ocultamento de implementação (*information hiding*) e modularização em sistemas de software desenvolvidos em C.

---

## 1. O que é um Tipo Abstrato de Dados (TAD)?
Um TAD é um modelo matemático composto por uma coleção de dados e um conjunto de operações definidas sobre esses dados:
- O usuário do TAD interage exclusivamente através da sua interface pública (as funções declaradas no arquivo `.h`).
- A representação interna dos dados (os campos da `struct` e alocação de memória) permanece estritamente oculta no arquivo `.c`.
- **Vantagem:** Permite alterar toda a estrutura interna (ex.: migrar de um vetor estático para uma lista encadeada ou árvore) sem quebrar nenhuma linha de código dos clientes que consomem a biblioteca.

---

## 2. Padrão de Estrutura Opaca (*Opaque Pointer*)

O padrão oficial em C consiste em declarar o ponteiro para a `struct` no arquivo de cabeçalho sem revelar seus membros:

```c
// ponto.h (Interface Pública do TAD)
#ifndef PONTO_H
#define PONTO_H

typedef struct ponto Ponto; // Tipo opaco

Ponto* ponto_cria(float x, float y);
void ponto_libera(Ponto* p);
void ponto_acessa(Ponto* p, float* x, float* y);
float ponto_distancia(Ponto* p1, Ponto* p2);

#endif
```

```c
// ponto.c (Implementação Privada do TAD)
#include <stdlib.h>
#include <math.h>
#include "ponto.h"

struct ponto {
    float x;
    float y;
};

Ponto* ponto_cria(float x, float y) {
    Ponto* p = (Ponto*) malloc(sizeof(Ponto));
    if (p != NULL) {
        p->x = x;
        p->y = y;
    }
    return p;
}

void ponto_libera(Ponto* p) {
    free(p);
}
```
