A décima aula de **Linguagem C** com o Professor Vinícius marcou a transição da programação puramente monolítica dentro da função `main` para o paradigma de **Modularização**, introduzindo a definição, assinatura, passagem de parâmetros por valor e retorno de valores em funções personalizadas.

---

## 1. Modularização e Responsabilidade Única
O Professor Vinícius enfatizou que programas reais não devem concentrar toda a lógica dentro do bloco `main`:
- A função principal (`main`) atua como orquestradora do fluxo de execução.
- As tarefas específicas (como cálculos matemáticos, validações e leitura de dados) devem ser isoladas em funções independentes, promovendo clareza, manutenibilidade e reutilização de código.

---

## 2. Assinatura, Parâmetros e Retorno de Funções
Foi demonstrada a sintaxe padrão de criação de funções em C, com o exemplo prático do cálculo de média ponderada/aritmética entre notas:

```c
#include <stdio.h>

// Declaração e definição da função modular
float calcularMedia(float nota1, float nota2) {
    float resultado = (nota1 + nota2) / 2.0;
    return resultado; // Retorna o valor calculado para quem chamou
}

int main() {
    float n1 = 7.5;
    float n2 = 5.5;

    // Chamada da função passando argumentos por valor
    float mediaFinal = calcularMedia(n1, n2);

    printf("Primeira nota: %.2f\n", n1);
    printf("Segunda nota : %.2f\n", n2);
    printf("Media final calculada: %.2f\n", mediaFinal);

    return 0;
}
```

- **Passagem por Valor:** As variáveis `n1` e `n2` têm seus valores copiados para os parâmetros `nota1` e `nota2` no momento da chamada da função, preservando os dados originais do escopo da `main`.
